# Запуск и проверка Mini App в Telegram

Telegram Mini App — это обычное веб-приложение, которое Telegram открывает по HTTPS-ссылке внутри
бота. Весь код находится в этом репозитории. Для работы нужны три вещи:

1. Бот, зарегистрированный через **@BotFather**.
2. Публичный **HTTPS**-адрес приложения (`localhost` не подходит: Telegram до него не достучится).
3. Токен бота в переменной окружения `TELEGRAM_BOT_TOKEN`: он нужен коду для проверки подписи
   `initData` (см. `src/lib/telegram/validate-init-data.ts`).

## Шаг 1. Создать бота

В Telegram откройте **@BotFather** и отправьте:

```text
/newbot
```

Задайте боту имя и username (username должен заканчиваться на `bot`, например `mystara_tarot_bot`).
BotFather пришлёт **токен** вида `123456789:AAExampleTokenValue`. Сохраните его, он понадобится в шаге 4.
Токен даёт полный контроль над ботом: не публикуйте его и не отправляйте в чаты.

## Шаг 2. Получить публичный HTTPS-адрес

### Вариант A. Развернуть на Vercel (рекомендуется)

Это основной способ развёртывания (см. раздел «Развёртывание» в `README.md`). Из корня проекта:

```bash
npx vercel
```

Команда попросит войти в аккаунт (откроет ссылку в браузере) и задаст несколько вопросов с
вариантами по умолчанию, достаточно нажимать Enter. В конце Vercel выдаст постоянный адрес вида
`https://taro-project-xxxx.vercel.app`: он понадобится в шаге 3.

После первого деплоя добавьте переменные окружения в панели Vercel (Project → Settings →
Environment Variables): минимум `AUTH_SECRET` и `TELEGRAM_BOT_TOKEN`. Остальные переменные из
`.env.example` необязательны.

### Вариант B. Туннель со своего компьютера (временный)

Для проверки в режиме разработки можно пробросить локальный сервер (`npm run dev`) наружу:

```bash
npx localtunnel --port 3000
```

Получите ссылку вида `https://xxxx.loca.lt`. При первом заходе localtunnel показывает страницу-
предупреждение «Tunnel website ahead» и просит ввести IP-адрес: это делается один раз на 7 дней для
одного IP. Проще всего один раз открыть ссылку в обычном браузере на том же устройстве и пройти эту
страницу, после чего Telegram загружает приложение напрямую.

Альтернатива без страницы-предупреждения:

```bash
npx cloudflared tunnel --url http://localhost:3000
```

Адрес туннеля меняется при каждом перезапуске, поэтому его придётся заново прописывать в BotFather
(шаг 3).

## Шаг 3. Прописать Mini App в BotFather

В @BotFather отправьте:

```text
/mybots
```

Затем выберите бота → **Bot Settings** → **Menu Button** → **Configure menu button**. Пришлите
HTTPS-адрес из шага 2 и любой текст кнопки (например, «Открыть»). У бота появится постоянная кнопка
меню, которая открывает Mini App.

## Шаг 4. Добавить токен в окружение

Локально добавьте в файл `.env` в корне проекта строку:

```text
TELEGRAM_BOT_TOKEN="токен_из_шага_1"
```

При проверке через Vercel добавьте ту же переменную в Project → Settings → Environment Variables
и выполните повторный деплой.

## Шаг 5. Открыть и проверить

Найдите бота в Telegram по username → **Start** → нажмите кнопку меню внизу. Должна открыться
главная Mini App с разделами «Таро», «Нумерология» и «Астрология».

Что стоит проверить:

- Шапка и подвал сайта скрыты: их заменяет собственная главная Mini App
  (`src/components/telegram/telegram-home.tsx`).
- Кнопка «Назад» в самом Telegram работает и возвращает на предыдущий шаг сценария.
- Основные действия экрана (перемешать, продолжить, сохранить) оформлены теми же золотыми кнопками,
  что и на сайте, но вынесены в нижнюю панель, закреплённую у края экрана (`PrimaryActionBar`).
  Нативной синей кнопки Telegram (MainButton) в приложении нет.
- Вход в аккаунт происходит автоматически и без пароля (серверная проверка `initData`, провайдер
  `telegram` в `src/lib/auth.ts`), но **только при заданном** `DATABASE_URL`. Без базы данных вход
  не сработает, а таро, нумерология и астрология продолжат работать в гостевом режиме.

## Если что-то не работает

- Пустой экран или ошибка загрузки: проверьте, что адрес из шага 2 открывается в обычном браузере,
  а не только на `localhost`.
- Кнопка меню не появляется: подождите, Telegram кэширует настройки бота, либо перезайдите в чат
  с ботом.
- Вход не работает: проверьте, что `TELEGRAM_BOT_TOKEN` совпадает с токеном от BotFather и что задан
  `DATABASE_URL` (без него вход отключён по замыслу, см. раздел «База данных» в
  `docs/ARCHITECTURE.md`).

## Ответы бота в чате (вебхук)

Mini App открывается и без вебхука, но чтобы бот отвечал на `/start`, `/help`, `/docs` и `/support`
кнопкой «Открыть Mystara» и ссылками на документы, нужен вебхук:
`src/app/api/telegram/webhook/route.ts` (тексты ответов — в `src/lib/telegram/bot-reply.ts`). Токен
ему для ответов не нужен: ответ возвращается прямо в ответе на запрос Telegram.

1. Придумайте длинный случайный секрет (буквы и цифры, до 256 символов) и добавьте в Vercel
   переменную `TELEGRAM_WEBHOOK_SECRET` с этим значением. Выполните повторный деплой.
2. Один раз зарегистрируйте вебхук (подставьте свои значения; токен и секрет не публикуйте):

   ```text
   https://api.telegram.org/bot<TOKEN>/setWebhook?url=<АДРЕС_САЙТА>/api/telegram/webhook&secret_token=<SECRET>
   ```

   Ответ должен быть `{"ok":true,...}`. Проверить регистрацию можно запросом `.../bot<TOKEN>/getWebhookInfo`.
3. Отправьте боту `/start`.

Без секрета вебхук отвечает 503, с неверным секретом — 403, поэтому посторонние управлять ботом не
могут.

## Оплата Звёздами

Для приёма оплаты Звёздами дополнительных ключей не нужно: достаточно `TELEGRAM_BOT_TOKEN`, зарегистрированного
вебхука и `DATABASE_URL`. Вебхук отвечает на `pre_checkout_query` и после `successful_payment`
начисляет кредиты (`src/lib/repositories/purchase.repository.ts`). Звёзды доступны только внутри бота и
Mini App, на сайте для оплаты используется ЮKassa.
